# E-Commerce Product and Order Management System

## Overview
A DBMS project built using Oracle SQL to manage customers, product categories, products, orders, order items, and payments in an e-commerce system.

## Technologies Used
- Oracle Database
- Oracle SQL
- VS Code with Oracle SQL Developer extension

## Database Design
The project contains six tables:
- **CUSTOMERS** — customer information
- **CATEGORIES** — product categories
- **PRODUCTS** — product details, prices, and stock
- **ORDERS** — customer orders and order status
- **ORDER_ITEMS** — products and quantities in each order
- **PAYMENTS** — payment details and status

## Concepts Implemented
- Primary keys and foreign keys
- Constraints: NOT NULL, UNIQUE, CHECK, and DEFAULT
- DDL: CREATE and ALTER
- DML: INSERT, UPDATE, and DELETE
- Single-row functions
- SQL operators and aggregate functions
- GROUP BY, HAVING, and ORDER BY

## Project Files
1. `01_create_tables.sql` — creates the database tables and constraints
2. `02_insert_data.sql` — inserts sample records
3. `03_ddl_dml.sql` — demonstrates ALTER, UPDATE, INSERT, and DELETE
4. `04_functions.sql` — demonstrates SQL single-row functions
5. `05_operators_aggregates.sql` — demonstrates operators and aggregate queries
